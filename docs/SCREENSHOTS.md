# Native UI screenshot

![openMaster Studio 84 editor](../assets/native-ui.png)

`assets/native-ui.png` was captured on macOS on 2026-10-27 from the actual **v1.2.0 VST3 editor**, compiled from the [v1.2.0 source](https://github.com/alanmarcero/openMaster/tree/v1.2.0). It shows the default Studio 84 faceplate while processing a stereo test signal at 48 kHz with a 120 BPM host transport.

A JUCE 8.0.9 host loads the VST3 and captures its native AppKit view at the display's backing resolution (2240 × 1440). All controls, labels, meters and version text come from the running plugin. The embedded faceplate texture is described in [the artwork record](../assets/ANALOG-CYBER.md).
